## Engineering Principles

1. Document actual results; distinguish completed work from planned work.
2. Prefer reproducible procedures over undocumented manual changes.
3. Protect credentials, personal information, and sensitive system data.
4. Validate changes before committing them.
5. Record failures and lessons learned, not only successful outcomes.

## About This Portfolio

The objective is to demonstrate practical engineering skills through small, documented, version-controlled deliverables that progressively combine into realistic projects.
