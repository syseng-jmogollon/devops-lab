# DevOps Lab

A hands-on learning and portfolio repository documenting my transition into DevOps, Cloud Engineering, Automation, and Platform Engineering.

## Purpose

This repository is my practical DevOps laboratory. It contains exercises, experiments, notes, scripts, infrastructure configurations, and projects developed throughout my professional transition.

The goal is not only to study DevOps technologies, but to demonstrate the ability to apply them in realistic environments.

## Learning Areas

- Linux and system administration
- Git and GitHub
- Bash and shell scripting
- Python automation
- Networking fundamentals
- Docker and containerization
- Ansible
- Terraform and Infrastructure as Code
- AWS and cloud engineering
- Kubernetes
- CI/CD
- Monitoring and observability
- Security fundamentals
